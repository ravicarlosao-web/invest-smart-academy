Adicionar os seguintes schemas em JSON-LD no `<head>` da página principal:

```json
{
  "@context": "https://schema.org",
  "@type": "EducationalOrganization",
  "name": "ALUKA",
  "description": "Plataforma de educação em trading 100% em português",
  "url": "https://aluka.app",
  "logo": "https://aluka.app/logo.png",

  "areaServed": ["AO", "BR", "PT"],
  "sameAs": [
    "https://instagram.com/aluka",

  ]

```

Adicionar schema `Course` para cada nível da trilha:

Adicionar schema `FAQPage` na página principal (quando o FAQ for criado).

**5. PERFORMANCE — Core Web Vitals**

Objectivos:
- LCP (Largest Contentful Paint): abaixo de 2.5 segundos
- INP (Interaction to Next Paint): abaixo de 200ms
- CLS (Cumulative Layout Shift): abaixo de 0.1

Implementar obrigatoriamente:
- Converter todas as imagens para formato **WebP**
- Adicionar **lazy loading** em todas as imagens (`loading="lazy"`)
- Implementar **CDN** para servir assets estáticos (Cloudflare é gratuito e recomendado)
- Activar **compresso Gzip ou Brotli** no servidor
- Minificar CSS e JavaScript em produção
- Adicionar cache headers nos assets estáticos (mínimo 1 ano para imagens e fonts)
- Pré-carregar fontes críticas com `<link rel="preload">`
- Remover JavaScript e CSS não utilizado (tree shaking)

---

**6. SITEMAP E ROBOTS**

- Gerar `sitemap.xml` dinâmico com todas as páginas públicas
- Submeter o sitemap no Google Search Console
- Configurar `robots.txt` correctamente:
```
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /dashboard/
Sitemap: https://aluka.app/sitemap.xml
```

---

**7. SEO TÉCNICO ADICIONAL**

- Garantir que **todas as imagens** têm atributo `alt` descritivo
- Garantir hierarquia correcta de headings: apenas **um H1 por página**, seguido de H2, H3
- Todos os links internos devem ter texto descritivo (nunca "clica aqui")
- Página 404 personalizada que redireciona o utilizador
- Redirect **301** para qualquer URL antiga com "tradeacademy"
- Garantir que a versão HTTPS está activa e que HTTP redireciona para HTTPS
- Garantir que `www` redireciona para `non-www` (ou o contrário) — nunca os dois activos ao mesmo tempo

---

**8. MOBILE FIRST — prioritário para Angola**

O público angolano acede maioritariamente por telemóvel. Verificar:
- Meta viewport configurado: `<meta name="viewport" content="width=device-width, initial-scale=1">`
- Todos os botões e links com área de toque mínima de 48x48px
- Fontes legíveis sem zoom (mínimo 16px no body)
- Teste no Google Mobile-Friendly Test deve passar a 100%
