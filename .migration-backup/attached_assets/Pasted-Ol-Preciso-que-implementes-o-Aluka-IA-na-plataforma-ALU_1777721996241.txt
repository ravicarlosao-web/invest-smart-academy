**1. PAINEL DE ADMINISTRADOR — Área de Chaves API**

Na secção de Integrações/Configurações de API que já existe no painel admin (onde está o Google OAuth), adicionar uma área separada chamada **"Inteligência Artificial"** com os seguintes campos:

**Modelo 1 — Análise Geral de Texto (Aluka IA)**
- Label: `Google Gemini — Análise de Texto`
- Campo: `Gemini API Key (Texto)`
- Descrição visível no painel: *"Usado pelo Aluka IA para analisar os dados do trade: entrada, saída, resultado, duração e gestão de risco."*
- Toggle para activar/desactivar este modelo

**Modelo 2 — Análise de Imagem de Gráficos**
- Label: `Google Gemini — Análise de Gráfico (Imagem)`
- Campo: `Gemini API Key (Imagem)`
- Descrição visível no painel: *"Usado pelo Aluka IA quando o aluno envia uma imagem do gráfico. Identifica padrões, suportes, resistências e avalia a qualidade da entrada."*
- Toggle para activar/desactivar este modelo

Notas importantes sobre a área de chaves:
- As duas chaves podem ser iguais (mesma API Key do Google AI Studio) ou diferentes — o admin decide
- As chaves devem ser guardadas encriptadas na base de dados
- Se uma chave não estiver configurada ou o toggle estiver desligado, a funcionalidade correspondente não aparece para o aluno — sem erros técnicos, apenas ausência silenciosa da função
- Se o aluno tentar usar o Aluka IA sem a chave configurada, mostrar popup: *"O Aluka IA ainda não está disponível. Em breve!"*

**2. ALUKA IA — Análise de Texto do Trade**

Após cada trade no simulador, o Aluka IA deve analisar automaticamente os seguintes dados e devolver feedback em português:

Dados a enviar para o Gemini:
```json
{
  "ativo": "BTC/USD",
  "tipo": "COMPRA",
  "entrada": 67500,
  "saida": 68200,
  "stop_loss": 67000,
  "resultado": "+$340",
  "duracao": "14 minutos",
  "racio_rr": "1:2.8",
  "saldo_atual": "$12.450"
}
```

Prompt base a usar:
```
És o ALUKA, um coach de trading experiente que ajuda iniciantes a aprender. Analisa este trade e dá feedback construtivo em português de Angola. Sê directo mas encorajador. Avalia: (1) qualidade da entrada, (2) gestão de risco e stop loss, (3) saída — saiu cedo ou tarde demais, (4) uma lição concreta para melhorar. Máximo 4 pontos curtos. Dados do trade: [inserir JSON acima]
```

Formato de resposta esperado na interface:
- Ícone ✅ para pontos positivos
- Ícone ⚠️ para pontos a melhorar
- Ícone 💡 para sugestões
- Ícone 🔥 para streak e consistência

**3. ALUKA IA — Análise de Imagem de Gráfico**

O fluxo funciona da seguinte forma:

1. O aluno tira um print/screenshot do gráfico no simulador
2. Esse print é **detectado automaticamente** pela plataforma — assim que o screenshot for feito, a imagem aparece directamente na interface do Aluka IA, sem o aluno precisar de fazer upload manual
3. Aparece a imagem na interface com um botão **"Analisar com Aluka IA"**
4. O aluno clica no botão — só nesse momento é que a imagem é enviada para o Gemini
5. O Aluka IA devolve a análise detalhada do gráfico

O aluno não precisa de procurar o ficheiro nem fazer upload — tira o print, vê a imagem aparecer, clica no botão. Simples.

Prompt base para análise de imagem:
```
És o ALUKA, um coach de trading experiente. Analisa este gráfico financeiro e responde em português de Angola. Identifica: (1) tendência actual — alta, baixa ou lateral, (2) padrões de velas visíveis, (3) níveis de suporte e resistência mais relevantes, (4) se há um sinal de entrada válido agora e porquê, (5) onde colocarias o stop loss. Sê claro e educativo — o aluno é iniciante.
```

Formato de envio para a API (multimodal):
```javascript
const response = await fetch("https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-pro:generateContent?key=" + API_KEY, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    contents: [{
      parts: [
        {
          inline_data: {
            mime_type: "image/jpeg",
            data: BASE64_DA_IMAGEM
          }
        },
        {
          text: "[inserir prompt acima]"
        }
      ]
    }]
  })
});
```
